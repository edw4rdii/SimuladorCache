# Simulador de Cache - Organização de Computadores

Autores: Eduardo Spezia e Joao Arnoldo Eger


## Estrutura
- `src/` código-fonte (C++17)
- `calibracao/` traços e respostas C1 a C4
- `experimentos/` traços E1 a E6 e do Desafio
- `resultados/` saídas das execuções
- `relatorio/` relatório final
- `scripts/` execução em lote
